# 📝 Todo App

A modern and responsive **Todo application** built using **HTML, SCSS, and Vanilla JavaScript (ES Modules)**.  
It supports **light/dark theme**, **filters**, **drag & drop reordering**, and **localStorage persistence**.

---

## 🌐 Live Demo

🔗 **Live Site:** [View Todo App](https://rawanyasser297.github.io/todo-app/)  
💻 **GitHub Repository:** [Todo App Repo](https://github.com/RawanYasser297/todo-list.git)

---

## 🚀 Features

- 🌗 **Light / Dark Theme Toggle**
- ➕ **Add new todos**
- ✅ **Mark todos as completed**
- 🧹 **Clear completed tasks**
- 🧮 **Items left counter**
- 🔄 **Filter by All / Active / Completed**
- 📦 **LocalStorage** support — keeps your todos after reload
- 🎨 **Built with SCSS** for modular and maintainable styling
- ♿ **Built with Accessibility in mind** — proper labels, focus states, and keyboard navigation
